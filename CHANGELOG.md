# Changelog

## 0.1.0 (unreleased)

- First release, extracted from a personal assistants repo: spec version 2 (default parallel cap 5), five read-only roles, `install` (with `--check` and `--uninstall`), `bin/miss-log`, templates for the binding and the delegation block, Claude Code and Antigravity CLI support.
- Hardened before the first release (review and audit, 2026-11-14): broken delegation markers stop the run instead of losing text; CRLF and blank lines are kept; every write stays inside the project (no absolute or `..` paths, no symlinks out); a failed run writes nothing; settings are type-checked and a model name cannot add frontmatter; roles allow only known keys and read-only tools; a renamed copy of a generated agent is never deleted; dropped harnesses are cleaned up; a symlinked `routewise/` installs into the project that holds it; the miss-log filter also refuses tokens, keys, hosts, IP addresses, ticket IDs, UUIDs and home paths.
- Second review and audit (2026-11-14): a role must list at least one tool, and only each harness's known read-only tool names are allowed; `harness.toml` tier values are checked like `[tiers]`; markers count only as whole lines outside fenced code; uninstall edits a symlinked instruction file through its target and never deletes the link; every target is checked for write access before anything is written, and files are written through a temporary file and a rename; paths are checked again right before each write, and the miss log is opened without following a symlink; `--project` must hold the routewise folder; the miss-log filter now aims at high precision (clear leaks only, normal code words pass) and normalises text first; Python runs with `-B`.
- `AGENTS.md` is the default home of the delegation block (`instructions = ["AGENTS.md"]`); routewise no longer creates `CLAUDE.md` by default and never creates symlinks. New `claude_md` setting (`auto`, `import`, `none`): an `@AGENTS.md` import block in an existing `CLAUDE.md` or `.claude/CLAUDE.md` (`@../AGENTS.md` there), so Claude Code (v2.1.277+) still reads `AGENTS.md`; notes for a lone `CLAUDE.local.md` and warnings for CLAUDE files above the project. Both fragments say a tool without the subagents does the work itself.
- Spec section 13: live check of routewise-generated agents on Claude Code 2.1.325 (2026-11-14).
- `--project` must be the folder that holds `routewise/` directly, or `routewise/` itself (spec S9): routewise can run on its own repo, and a folder further up (such as `~`) is now refused.
- Spec section 13: live check of `AGENTS.md` and the `@AGENTS.md` import on Claude Code 2.1.325 (2026-11-14).
- Development: `make check` also scans for secrets with gitleaks (history and staged changes); `make hooks` enables a tracked pre-commit hook that runs `make check`; typecheck runs pyright in the project environment; `uv.lock` is now tracked.
